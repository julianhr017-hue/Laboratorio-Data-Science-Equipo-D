# Laboratorio de Data Science - Equipo D

Laboratorio práctico desarrollado en Python utilizando Jupyter Notebook, Pandas y Scikit-learn.

## Contenido

- Módulo 1: Extracción y unión de datos con Pandas.
- Módulo 2: Filtrado múltiple de datos.
- Módulo 3: Clasificación con SVC y optimización mediante GridSearchCV.

## Ejecución

El notebook principal es:

`Laboratorio_Practico_Data_Science.ipynb`

Puede ejecutarse localmente con JupyterLab o cargarse directamente en Google Colab.

## Dependencias

- pandas
- scikit-learn
- jupyterlab
